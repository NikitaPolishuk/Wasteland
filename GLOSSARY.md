# Wasteland

Термины игрового мира Wasteland.

## Язык

**Тип здания**:
Уникальная разновидность здания с общими характеристиками, применяемыми к его экземплярам в игре. Название типа можно изменить, сохранив его идентичность.

**Экземпляр здания**:
Отдельное здание определённого типа в игровом мире. У одного типа может быть несколько экземпляров.
